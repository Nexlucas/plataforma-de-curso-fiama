<h1>plataforma-de-curso-fiama<h1/>

<h3>Uma escola técnica deseja desenvolver uma API para gerenciar seus alunos e cursos.<h3/>

<h3>Atualmente, um aluno pode participar de diferentes cursos oferecidos pela escola. Da mesma forma, um mesmo curso pode ter diversos alunos matriculados.
<h3/>

<h3>A aplicação permiti o cadastro e o gerenciamento dessas informações.<h3/>
