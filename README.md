<h1>plataforma-de-curso-fiama<h1/>

<p>Uma escola técnica deseja desenvolver uma API para gerenciar seus alunos e cursos.<p/>

<p>Atualmente, um aluno pode participar de diferentes cursos oferecidos pela escola. Da mesma forma, um mesmo curso pode ter diversos alunos matriculados.
<p/>

<p>A aplicação permiti o cadastro e o gerenciamento dessas informações.<p/>
